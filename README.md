# Волга-Металл-Сервис · демо B2B-сайта

Демонстрационный сайт металлообрабатывающего предприятия из портфолио студии Akimov Web. Организация, станки, цены и клиенты вымышлены.

## Что умеет сайт

- Главная с чертежом пластины, который «рисуется» на глазах, и лазерным лучом по контуру.
- Каталог услуг: лазерная резка, гибка, сварка, порошковая окраска, металлоконструкции. У каждой своя страница с параметрами, примером заказа и вопросами.
- Калькулятор стоимости с НДС 20%: операция, материал, толщина, объём, срочность, скидки за объём и ближайшая дата отгрузки.
- Запрос коммерческого предложения с чертежом (DXF, DWG, STEP, PDF). Это демо: файл никуда не загружается, запрос хранится только в браузере посетителя.
- Оборудование цеха, проекты с характеристиками партий, процесс работы, клиенты, вопросы и ответы.
- Светлая и тёмная темы, мобильная версия, сайт закрыт от индексации.

## Стек

Next.js (App Router, статический экспорт), TypeScript, Tailwind CSS v4, Motion, React Hook Form и Zod, lucide-react. Бэкенда нет.

Макет, по которому сделан сайт, лежит в `design/maket-4.html`.
